# Templates Library

Templates Library es una librería Python para automatizar tareas repetitivas en
proyectos académicos y técnicos:

- creación de estructuras de proyectos;
- organización de resultados generados por scripts;
- conversión de Markdown a LaTeX con plantillas institucionales;
- reutilización de plantillas empaquetadas con la librería.

## Estructura de módulos

- `templates_library.modulos.proyectos`: creación de proyectos.
- `templates_library.modulos.resultados`: guardado y listado de resultados.
- `templates_library.modulos.conversion`: conversión de Markdown a LaTeX.
- `templates_library.utils`: utilidades internas compartidas.
