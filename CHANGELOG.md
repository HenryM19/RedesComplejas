# Changelog

Todas las notas relevantes de este proyecto se documentarán en este archivo.

El formato sigue una versión simple basada en [Keep a Changelog](https://keepachangelog.com/)
y versionado semántico.

## [0.1.0] - 2026-05-14

### Added

- Estructura profesional `src-layout` con paquete `templates_library`.
- API pública para crear proyectos, organizar resultados y convertir Markdown a LaTeX.
- Entry points CLI: `create-project`, `crear-proyecto` y `md-a-latex`.
- Inclusión de plantillas como datos del paquete.
- Archivos base para publicación en PyPI: `pyproject.toml`, `LICENSE`, `README.md` y `CONTRIBUTING.md`.
