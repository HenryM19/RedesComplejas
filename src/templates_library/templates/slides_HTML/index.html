Conclusiones

Hallazgos

  • Formato Deck autocontenido con navegación por teclado, botones y barra de progreso.
  • Reutilizable Sustituye títulos, tarjetas, tablas e iframes sin tocar el JavaScript.
  • Consistente Mantiene colores, jerarquía visual y espaciado del archivo original.

Checklist de edición

  1. Duplica una diapositiva existente y cambia solo el contenido.
  2. Si insertas HTML interactivo, colócalo en la carpeta embeds.
  3. Conserva las clases CSS para mantener el mismo diseño.
